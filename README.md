# QazLearn — Изучение казахского языка

Адаптивное веб-приложение для изучения казахского языка русскоязычными пользователями.

## Запуск

```bash
npm install
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`.

## Сборка

```bash
npm run build
```

Готовая сборка будет в папке `dist/`.

## Возможности

- Изучение слов и устойчивых фраз
- Переворачивающиеся карточки (казахский → русский / русский → казахский)
- Режим скрытого перевода с эффектом стирания маски
- Практика перевода (ввод текста, выбор ответа, сбор фразы)
- Алгоритм интервального повторения
- Отслеживание прогресса и целей
- Импорт и экспорт CSV
- Светлая и тёмная темы
- Полностью офлайн после загрузки

## Структура проекта

```
src/
  components/   # UI-компоненты
  pages/        # Страницы приложения
  lib/          # Утилиты (CSV, хранилище, повторение)

public/data/    # CSV-словарь
```
